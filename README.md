# Práctica 11 - Archivo y SDCard

Aplicación Android nativa desarrollada con Kotlin y Jetpack Compose.

Reproductor MP3 con selección de audio desde el explorador de archivos, reproducción, pausa, detención con retorno al inicio y barra de progreso con tiempos.

Lectura y escritura de texto en almacenamiento interno y externo mediante File, FileInputStream y FileOutputStream.

Acceso a documentos de texto en almacenamiento compartido y SDCard mediante Storage Access Framework.

Permisos de almacenamiento adaptados a la versión de Android.
